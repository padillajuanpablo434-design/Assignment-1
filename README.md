# GoCycle — SENG 300 Fall 2026 Assignment 1

GoCycle is a Java application developed for SENG 300 (Fall 2026) Assignment 1 at the University of Calgary. This repository contains the team's source code, build configuration, and documentation for the assignment.

## Build and Run

Requires Java 17 and Maven 3.6 or later.

```sh
mvn compile    # compile the sources into target/classes
mvn test       # compile and run the JUnit 5 tests
```

To run the demo after compiling:

```sh
java -cp target/classes gocycle.app.Main
```
